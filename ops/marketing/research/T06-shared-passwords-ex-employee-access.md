## The problem in the owner's words
"Everybody in the shop uses the same login for the booking page, and nobody knows the password anymore."
"The guy who left in March still gets the emails."
"I can't change the password without breaking the front desk."

## What is actually going on
CISA says multifactor authentication helps ensure that only authorized users can access business accounts [1].
CISA advises turning on MFA across systems such as email, file storage and remote access [1].
CISA says businesses should aim to use a phishing-resistant MFA method [1].
CISA describes SMS and email codes as the form of MFA that provides the weakest protection [1].
CISA advises using a different strong password for each account [2].
CISA describes a password manager as a program that generates, stores and fills in passwords [2].
CISA says password managers can tell you when you have weak or re-used passwords [2].
CISA's password guidance does not address sharing one password among several people [2].
CISA's small business guidance says to enable MFA for all system administrator accounts, because admin accounts are high-value targets [3].
NIST SP 800-53 control PS-4 (Personnel Termination), as summarized by UpGuard, says system access must be disabled within a defined time period after a person is terminated [4].
The same summary says all authenticators and credentials associated with that person must be terminated or revoked [4].

## Post angles
- The front desk login stops working the morning after the manager quits, and nobody knows the new password.
- A password written on a sticky note by the register is the only record of the booking system login.
- A former stylist still has an active admin login to the booking system.
- One afternoon brings five requests for the same shared password, from the Wi-Fi, the shop email and the card reader.
- A text code arrives on a phone that belongs to someone who no longer works at the shop.
- A vendor asks which login the invoices should go to, and the owner realizes the answer is a shared account.
- Changing the one password everyone uses, then finding out nobody wrote down where it is used.
