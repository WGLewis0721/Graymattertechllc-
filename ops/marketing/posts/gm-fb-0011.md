Write down every place you type the same customer's name this week.

Check each one:

1. The booking app or calendar
2. A Messenger or Instagram reply
3. Your invoice or receipt tool
4. A notebook, spreadsheet, or sticky note

If a detail shows up in more than two places, it's a candidate to automate. Start with the one you retype most. A form that feeds a spreadsheet is a simple first step, and the help pages for Google Forms explain how to set one up.
