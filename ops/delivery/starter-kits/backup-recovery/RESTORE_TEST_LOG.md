## 3-2-1 in plain words

- **3 copies:** the working file, plus two backups.
- **2 kinds of storage:** for example the laptop disk plus a cloud account, or a cloud account plus an external drive.
- **1 copy off-site:** a copy that is not in the same building as the device, such as a cloud account.

## If a device fails

1. Do not turn the failed device on again, and do not write new files to its drive.
2. Sign in to the cloud backup account from a working device, using the client’s own login.
3. Restore the files on the cannot-be-lost list to a new device or a new folder.
4. Open one file from each folder and record the result in the restore tests table.
