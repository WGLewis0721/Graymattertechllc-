# Source / build notes

`gm-approved-logo-reference.png` is the user-approved visual reference. It is included so future implementers do not reinterpret the logo.

`gm-mark-master.svg` is the production vector master derived from that approved reference. All primary, cobalt, reversed, monochrome, lockup, and favicon variants use this same path.

Production wordmarks use Montserrat ExtraBold/Bold converted to SVG paths. Raster files are compatibility exports of the SVG masters.
