## Required rules

- Place these files as `<img>` elements. Do not regenerate or trace them as SVG.
- Preserve aspect ratio: use `height: auto`; do not crop or stretch.
- Keep the logo clear of nearby controls and navigation labels.
- Use `alt="Gray Matter — Digital and Technology Solutions"` for the primary horizontal logo. Use `alt="Gray Matter"` for the icon-only mark.
- Brand palette: Deep Ink Navy `#152238`, Cobalt Blue `#2F64D6`, Warm Off-White `#F7F4ED`.

The complete uploaded approval board is retained at `../../source/gm-approved-logo-reference.png` for visual comparison only; it is not a website asset.
