## Architecture
This is intentionally a buildless GitHub Pages site:
- `index.html` — structure/content
- `style.css` — design system/responsive layout
- `script.js` — mobile menu, active nav, static email-form behavior

Do not add a framework, package manager, CMS, backend, or build pipeline unless the project owner explicitly requests it.

## Visual source of truth
The approved direction is midnight navy + ANR red + white/light-gray information surfaces, cinematic Alaska/aurora imagery, restrained Shee Atiká/Alaska Native-inspired geometric accents, bold mission-oriented typography, and federal contracting proof.

Do **not** revert to the earlier teal-heavy minimalist concept or generic black/neon cybersecurity styling.
