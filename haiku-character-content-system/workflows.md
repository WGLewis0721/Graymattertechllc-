# Operating Workflows

## Daily (30–60 min once running)

- Morning: Check yesterday’s posts. Reply to comments in the first hour.
- Content: Pull next scripted situation. Generate motion graphic or character clip. Add captions and first-second hook.
- Post: 1 video to TikTok + Instagram Reels.
- End of day: Save useful comments as future situation ideas.

## Weekly (2–3 hours)

- Batch generate 5–7 videos.
- Review performance: which situations held attention, which jobs/tasks got comments.
- Character consistency check (voice, pacing, reactions).
- Add 7–10 new situations to the list.

## Monthly (half day)

- Rank videos by watch time and follows gained.
- Refine character reference set.
- Evaluate motion graphics vs character clips and shift ratio.
- Build next month’s situation calendar from winning patterns.

The daily work stays small and repetitive. Weekly and monthly reviews decide which situations and which version of the character are actually performing.
