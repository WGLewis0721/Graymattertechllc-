# Haiku Character Social Media Content System

A system for growing a TikTok/Instagram account where a consistent fictional character moves through everyday work situations. Viewers learn practical AI model usage (starting with Claude Haiku) by following the character, without the account being pitched as an AI or Haiku channel.

The character is the constant. The job and setting change to fit the story. The lesson is a byproduct of watching the situation resolve.

## Core Principles

- Niche-first branding (post as the character’s life and work, not as an AI tool account)
- One recognizable character across many different jobs/settings
- Situations that look like they need a heavier model, resolved with Haiku medium + tight prompting
- Viewer learns by following the character, not by watching tutorials
- Heavy automation with progressive approval gates that learn from validated successes
