# Recommended Remotion Repos (for Atlas-style promos)

Fork these instead of starting from zero. They provide the kinetic text, logo reveals, UI mockups, and product scene structure.

1. **EveryInc/product-launch-video** — Claude skill + scaffold for polished 15-30s launches. Closest to 80% done.
2. **AleBrito124356/remotion-video-templates** — Prop-driven PromoTemplate, LogoIntro, KineticText. Zod schemas for easy editing.
3. **zz41354899/SwiftClip** — Large library of production templates (Product Launch, SaaS Promo, Brand Reveal).
4. **meetmati-ai/MATI-teaser** — Full teaser source ready to rebrand.
5. **codeverbojan/remotion-cinematic** — Feature announcements from screenshots/recordings.

Official starter: `npx create-video@latest --prompt-to-motion-graphics`

Pair any of these with Claude/ChatGPT for customization and Higgsfield/Kie.ai for generative assets.
