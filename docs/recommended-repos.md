# Recommended Repos for Atlas-style / Product Promos

## Remotion Bases (fork one)

1. **EveryInc/product-launch-video** — Claude skill + scaffold for polished 15-30s launches. Closest to 80% done.
2. **AleBrito124356/remotion-video-templates** — Prop-driven PromoTemplate, LogoIntro, KineticText. Zod schemas for easy editing.
3. **zz41354899/SwiftClip** — Large library of production templates (Product Launch, SaaS Promo, Brand Reveal).
4. **meetmati-ai/MATI-teaser** — Full teaser source ready to rebrand.
5. **codeverbojan/remotion-cinematic** — Feature announcements from screenshots/recordings.

Official starter: `npx create-video@latest --prompt-to-motion-graphics`

## Claude / Code-Driven Tools (added)

| Repo | Why |
|------|-----|
| [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) | Highest match for clean product launch films. Claude/Codex skill with shot recipe cards, Remotion templates, 2.5D moves, beat-sync, and sound design. Editable cinematic promos from real UI. |
| [lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) | Claude Code skill with 99 film styles made entirely in code. Good for stylized explainers and varied looks. |
| [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos) + [joeseesun/opus-video-prompts](https://github.com/joeseesun/opus-video-prompts) | Prompt packs of real Opus 5.5 code-rendered videos. Reference material for strong prompting. |
| [JohnHeibel/ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase) | Hand-painted cartoon starter (p5.js). Only if you want illustrated character style. |

Pair any of these with Claude/ChatGPT for customization and Higgsfield/Kie.ai for generative assets.
