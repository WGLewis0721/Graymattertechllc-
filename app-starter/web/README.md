# Web starter

Vite + React + TypeScript + Vitest. The demo's task list can add, edit, complete, delete, undo and persist in browser localStorage. No production database or auth.

Commands after generation: npm install; npm run test; npm run build; npm run dev.

For production design/architecture, read app-design/WEB_PLAYBOOK.md and app-design/SECURITY_AND_RELEASE.md in the generated project.

**Required on new projects:** Follow app-design/DESIGN_TO_BUILD_CONTRACT.md. The React task list is only a demo; complete the brand board, UI kit, screen-specific designs, and real implementation of every page in design/requested-screens.json.
